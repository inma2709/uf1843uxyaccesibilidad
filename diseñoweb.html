Diseño web: crear interfaces claras y adaptables

Accesibilidad Usabilidad Planificación Diseño web Código y evaluación

Diseñar una página web no consiste únicamente en elegir colores, fotografías o tipografías atractivas. Consiste en organizar la información y presentar los elementos de manera que las personas puedan comprender el contenido y utilizar la interfaz con facilidad.

Imagina dos páginas de una biblioteca. Ambas contienen exactamente la misma información: horarios, catálogo, préstamos y contacto.

En la primera, todos los textos tienen un tamaño parecido, los botones están dispersos y no existe una separación clara entre las secciones.

En la segunda, encontramos un título reconocible, un menú coherente, un buscador destacado y bloques de información bien organizados.

Aunque el contenido sea idéntico, la segunda página puede resultar mucho más sencilla de comprender y utilizar.

Idea fundamental: el diseño visual debe ayudar a comprender la información y completar tareas. La estética es importante, pero nunca debería dificultar la usabilidad ni la accesibilidad.

Qué aprenderás en este tema

Aprenderás a utilizar la jerarquía visual, la tipografía, el color y el espaciado para organizar una interfaz.

También comprenderás qué significa diseñar de forma responsive, cómo funciona el enfoque mobile-first y cuándo utilizar Flexbox o CSS Grid.

Finalmente, realizarás una actividad práctica para construir un diseño que se adapte a diferentes anchuras de pantalla.

1. Los principios fundamentales del diseño web

Un buen diseño no depende de una tendencia visual concreta. Existen principios que mantienen su utilidad porque responden a necesidades reales de las personas.

Jerarquía visual

Permite distinguir qué información es más importante mediante tamaños, espacios, orden y presentación.

Legibilidad

Facilita la lectura mediante tipografía adecuada, contraste suficiente y una distribución cómoda del texto.

Coherencia

Mantiene criterios comunes en botones, enlaces, títulos, colores y componentes.

Adaptabilidad

Permite que el contenido se reorganice en diferentes tamaños de pantalla sin perder información ni funcionalidad.

Estos principios están relacionados entre sí. Por ejemplo, una jerarquía bien construida puede facilitar la lectura y ayudar a encontrar las acciones principales.

2. Jerarquía visual: mostrar qué es importante

La jerarquía visual es la forma de organizar y presentar los elementos de una página para que las personas puedan identificar su importancia y sus relaciones.

No toda la información debe llamar la atención con la misma intensidad.

En una página de biblioteca, el nombre de la sección y el buscador de libros probablemente necesitarán más protagonismo que un aviso secundario situado al final de la pantalla.

¿Cómo se crea una jerarquía visual?

Tamaño

Los títulos suelen tener mayor tamaño que los párrafos para señalar la estructura del contenido.

Espaciado

Los espacios permiten separar secciones y agrupar elementos que están relacionados.

Posición y orden

Los elementos importantes deben aparecer en lugares donde resulten fáciles de encontrar.

Énfasis

El peso tipográfico y el contraste pueden destacar información sin necesidad de utilizar muchos colores diferentes.

Ejemplo con HTML

Imagina una página con un buscador de libros. Primero debemos organizar su contenido de forma lógica: 

<main>
  <h1>Catálogo de la biblioteca</h1>

  <p>
    Encuentra libros por título o autor.
  </p>

  <form action="/buscar" method="get">
    <label for="busqueda">
      Buscar libros
    </label>

    <input
      type="search"
      id="busqueda"
      name="q"
    >

    <button type="submit">
      Buscar
    </button>
  </form>
</main>

En este ejemplo, h1 identifica el título principal, el párrafo introduce la función y el formulario permite realizar la búsqueda.

El atributo action="/buscar" representa una ruta de ejemplo: el formulario necesitaría un servicio que procesara esa búsqueda para funcionar.

Después podemos utilizar CSS para mejorar la presentación: 

h1 {
  font-size: 2rem;
  line-height: 1.2;
  margin-bottom: 1rem;
}

form {
  margin-top: 1.5rem;
}

button {
  padding: 0.75rem 1rem;
}

El tamaño y el espacio contribuyen a destacar el título y separar el formulario del texto introductorio.

Importante: la jerarquía visual debe acompañar a la estructura semántica del HTML. Un texto no se convierte en un encabezado accesible simplemente porque lo mostremos con una letra grande.

3. Tipografía y legibilidad

La tipografía influye directamente en la facilidad con la que podemos leer y comprender una página web.

No se trata únicamente de escoger una fuente atractiva. También debemos prestar atención al tamaño, la separación entre líneas, el ancho de los párrafos y el contraste.

Tamaño del texto

Es recomendable utilizar unidades relativas como rem para facilitar la adaptación a las preferencias de lectura.

Por ejemplo: 

body {
  font-size: 1rem;
}

h1 {
  font-size: 2rem;
}

h2 {
  font-size: 1.5rem;
}

La unidad rem toma como referencia el tamaño de fuente del elemento raíz del documento. Si este tamaño es de 16 píxeles, 2rem equivale a 32 píxeles.

Sin embargo, su valor final depende de la configuración y de los estilos del documento.

Espaciado entre líneas

Un texto con líneas demasiado juntas puede resultar incómodo, especialmente cuando contiene párrafos largos. 

p {
  line-height: 1.6;
}

La propiedad line-height controla la altura de cada línea. Un valor sin unidad se calcula a partir del tamaño de la fuente.

Longitud de las líneas

En pantallas grandes, los párrafos que ocupan toda la anchura disponible pueden resultar difíciles de seguir.

Podemos limitar la longitud aproximada de las líneas utilizando la unidad ch. 

article p {
  max-width: 70ch;
}

La unidad ch está relacionada con el ancho del carácter cero de la fuente. Es una referencia útil para limitar la longitud de lectura, aunque no equivale exactamente a contar caracteres por línea.

Buenas decisiones tipográficas

  • Utilizar un tamaño de texto cómodo para la lectura.
  • Mantener una separación suficiente entre líneas y párrafos.
  • Evitar bloques extensos escritos completamente en mayúsculas.
  • No justificar textos si produce espacios irregulares que dificultan la lectura.
  • Mantener un número reducido y coherente de estilos tipográficos.
Recuerda: una página no es más profesional porque utilice letras pequeñas. La legibilidad debe tener prioridad sobre las preferencias estéticas.

4. Color y contraste: diseñar para comprender

El color puede ayudarnos a diferenciar secciones, destacar acciones y mantener una identidad visual coherente.

Sin embargo, utilizar muchos colores no garantiza que la página resulte más clara o más atractiva.

Una paleta sencilla

Para comenzar podemos trabajar con una selección limitada:

  • Un color principal para elementos destacados y acciones importantes.
  • Colores neutros para fondos, bordes y superficies.
  • Un color de texto que permita una lectura cómoda.
  • Colores de estado para errores, advertencias o confirmaciones, acompañados de mensajes claros.

El contraste no es opcional

El contraste indica la diferencia de luminosidad entre dos colores. Si el texto tiene poco contraste respecto al fondo, algunas personas encontrarán dificultades para leerlo.

Como estudiamos en el tema de accesibilidad, las WCAG establecen criterios de contraste para el texto y para determinados elementos de la interfaz.

Para comprobar una combinación puedes utilizar:

WebAIM Contrast Checker

Introduce los colores de primer plano y fondo, comprueba el resultado correspondiente al texto que estás utilizando y ajusta la combinación si es necesario.

El color no debe ser la única señal

Imagina un formulario en el que los campos incorrectos aparecen únicamente con un borde rojo.

Una persona que no distingue ese color podría no identificar el problema.

Es mejor incorporar también un mensaje como:

Revisa el correo electrónico. Introduce una dirección con un formato válido, como nombre@dominio.es.
Cómo comprobarlo: revisa si las acciones, errores y estados siguen siendo comprensibles cuando no puedes distinguir sus colores.

5. Diseño responsive: una web para diferentes pantallas

Actualmente una misma página puede consultarse desde teléfonos móviles, tabletas, ordenadores portátiles y monitores de gran tamaño.

El diseño responsive permite adaptar la distribución del contenido al espacio disponible.

No consiste simplemente en reducir el tamaño de todos los elementos. En muchas ocasiones necesitamos reorganizar las columnas, los menús, las imágenes y los espacios.

Ejemplo: un catálogo de libros

En un ordenador amplio podemos mostrar tres tarjetas de libros en una misma fila.

En un móvil, lo habitual será disponer esas tarjetas en una sola columna para facilitar la lectura y la interacción.

Pantalla estrecha

Las tarjetas pueden ocupar una columna y aprovechar el espacio disponible sin provocar desplazamiento horizontal innecesario.

Pantalla amplia

Las tarjetas pueden distribuirse en varias columnas si existe espacio suficiente para mantener una lectura cómoda.

¿Qué significa mobile-first?

Mobile-first es un enfoque de diseño que comienza por las necesidades y limitaciones de una pantalla estrecha.

Primero organizamos el contenido esencial para ese espacio y después incorporamos mejoras de distribución cuando aumenta la anchura disponible.

No significa eliminar funciones importantes en la versión móvil. Las tareas principales deben seguir disponibles independientemente del dispositivo.

¿Para qué sirven las media queries?

Las @media de CSS permiten aplicar estilos cuando se cumplen determinadas condiciones.

Por ejemplo, podemos mostrar inicialmente una columna y utilizar dos columnas a partir de una determinada anchura: 

.catalogo {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

@media (min-width: 48rem) {
  .catalogo {
    grid-template-columns: repeat(2, 1fr);
  }
}

El ejemplo comienza con una columna. Cuando el área de visualización alcanza el ancho indicado, las tarjetas pasan a dos columnas.

El valor 48rem es un punto de ruptura de ejemplo, no una medida obligatoria para todos los proyectos.

Importante: los puntos de ruptura deben elegirse según el comportamiento real del contenido, no exclusivamente según modelos de teléfonos o tabletas.

Diseños flexibles y reflow

Una página adaptable también debe permitir ampliar el contenido sin perder información ni funcionalidad.

Se conoce como reflow la reorganización del contenido cuando cambia el espacio disponible.

Debemos evitar que las personas tengan que desplazarse horizontalmente para leer cada línea de un texto corriente.

Algunos contenidos, como determinadas tablas extensas, pueden necesitar un tratamiento particular.

6. Flexbox y CSS Grid: organizar los elementos

CSS dispone de diferentes sistemas para distribuir los elementos dentro de una página.

Dos de los más utilizados son Flexbox y CSS Grid.

6.1. Flexbox

Flexbox es especialmente útil cuando queremos organizar elementos principalmente en una dirección: una fila o una columna.

Por ejemplo, podemos utilizarlo para distribuir los enlaces de un menú.

HTML

<nav class="menu-ejemplo"
     aria-label="Menú de biblioteca">
  <a href="#catalogo">Catálogo</a>
  <a href="#horarios">Horarios</a>
  <a href="#contacto">Contacto</a>
</nav>

Las tres anclas son destinos de ejemplo: para que funcionen, el documento debe contener elementos con los identificadores correspondientes.

CSS

.menu-ejemplo {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}

Vamos a interpretar el código:

  • display: flex activa Flexbox.
  • flex-wrap: wrap permite que los elementos pasen a otra línea cuando no caben.
  • gap: 1rem establece separación entre los elementos.

El resultado es un conjunto de enlaces que puede reorganizarse cuando cambia el espacio disponible.

6.2. CSS Grid

Grid está pensado para organizar elementos mediante filas y columnas.

Es una buena opción para construir galerías, catálogos o distribuciones más complejas.

Por ejemplo, podemos organizar varias tarjetas de libros con el siguiente HTML:

HTML

<section class="catalogo-ejemplo">
  <article>
    <h3>Libro A</h3>
    <p>Descripción del libro A.</p>
  </article>

  <article>
    <h3>Libro B</h3>
    <p>Descripción del libro B.</p>
  </article>

  <article>
    <h3>Libro C</h3>
    <p>Descripción del libro C.</p>
  </article>
</section>

CSS

.catalogo-ejemplo {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
  gap: 1rem;
}

Este ejemplo contiene varias propiedades importantes:

  • display: grid activa CSS Grid.
  • grid-template-columns define cómo se distribuyen las columnas.
  • repeat() permite repetir un patrón de columnas.
  • auto-fit ajusta el número de columnas según el espacio disponible.
  • minmax() establece tamaños mínimos y máximos.
  • 1fr representa una fracción del espacio disponible dentro de la cuadrícula.

La expresión min(100%, 16rem) evita imponer un mínimo de 16rem cuando el contenedor sea más estrecho.

De esta forma podemos crear columnas adaptables sin definir un punto de ruptura para cada tamaño de pantalla.

¿Cuándo utilizar Flexbox y cuándo Grid?

Comparación entre Flexbox y CSS Grid
Característica Flexbox Grid
Organización principal Una dimensión cada vez. Filas y columnas.
Ejemplo habitual Menú de navegación. Catálogo de tarjetas.
Distribución Alineación y reparto de elementos flexibles. Definición de una cuadrícula y colocación de elementos.
Adaptación Puede ajustar tamaños y envolver elementos. Puede crear columnas adaptables automáticamente.
Recuerda: Flexbox y Grid no compiten. Es habitual utilizar Grid para distribuir las grandes zonas de una página y Flexbox dentro de algunos componentes.

7. Coherencia y sistemas de diseño

Una web puede contener muchas páginas y componentes. Si cada uno utiliza colores, tamaños y comportamientos diferentes, la experiencia puede resultar confusa.

Para mantener la coherencia podemos definir un conjunto de decisiones reutilizables conocido como sistema de diseño.

Un sistema de diseño puede incluir:

  • Colores y sus usos.
  • Tipografías y tamaños.
  • Espaciado.
  • Estilos de botones y enlaces.
  • Componentes reutilizables.
  • Estados de error, éxito y carga.
  • Indicaciones de accesibilidad.
  • Documentación de patrones de uso.

Variables CSS para mantener coherencia

En CSS podemos utilizar propiedades personalizadas para centralizar algunos valores del diseño. 

:root {
  --color-principal: #174ea6;
  --color-texto: #222222;
  --color-fondo: #ffffff;
  --espacio-base: 1rem;
}

body {
  color: var(--color-texto);
  background-color: var(--color-fondo);
}

h1 {
  color: var(--color-principal);
}

article {
  padding: var(--espacio-base);
}

El selector :root permite declarar propiedades que pueden reutilizarse en todo el documento.

La función var() recupera su valor.

Si necesitamos modificar el color principal del proyecto, podemos cambiar una variable en lugar de buscar ese valor en múltiples reglas CSS.

Estos valores son ilustrativos. Antes de utilizarlos en una interfaz debemos comprobar el contraste en las combinaciones reales.

Material Design como referencia

Existen sistemas de diseño públicos que pueden utilizarse para aprender cómo se documentan componentes, patrones de interacción y decisiones visuales.

Un ejemplo conocido es Material Design .

Su documentación puede servir como referencia, pero no debemos copiar un sistema visual sin valorar las necesidades de nuestro propio proyecto.

Cuidado con las tendencias: una interfaz llamativa no es necesariamente una interfaz adecuada. Los textos demasiado pequeños, los contrastes insuficientes y los movimientos innecesarios pueden perjudicar la experiencia.

El rendimiento también importa

Una página que tarda demasiado en mostrar su contenido puede dificultar la realización de tareas, especialmente en conexiones lentas.

Por eso conviene utilizar imágenes optimizadas, evitar recursos innecesarios y mantener una estructura comprensible mientras la página carga.

La calidad del diseño también depende del funcionamiento real, no solo de una imagen estática del resultado.

8. Actividad práctica: crea un catálogo responsive

En esta actividad vamos a construir un pequeño catálogo de libros que se adapte automáticamente al tamaño de la pantalla.

Objetivo

Comprender cómo CSS Grid permite distribuir tarjetas en una o varias columnas según el espacio disponible.

Material necesario

  • Un editor de código.
  • Un navegador web.
  • Un archivo HTML.

Paso 1. Crea el documento HTML

Crea un archivo llamado catalogo.html y copia el siguiente código.

Este ejemplo es independiente del manual: puedes guardarlo y abrirlo directamente en el navegador. 

<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta
    name="viewport"
    content="width=device-width, initial-scale=1"
  >
  <title>Catálogo de libros</title>

  <style>
    * {
      box-sizing: border-box;
    }

    body {
      font-family: system-ui, sans-serif;
      line-height: 1.5;
      margin: 0;
      padding: 1rem;
      color: #222;
      background: #fff;
    }

    main {
      max-width: 70rem;
      margin-inline: auto;
    }

    .catalogo {
      display: grid;
      grid-template-columns:
        repeat(
          auto-fit,
          minmax(min(100%, 16rem), 1fr)
        );
      gap: 1rem;
    }

    .libro {
      border: 1px solid #aaa;
      border-radius: 0.5rem;
      padding: 1rem;
    }
  </style>
</head>

<body>
  <main>
    <h1>Catálogo de libros</h1>

    <div class="catalogo">
      <article class="libro">
        <h2>Libro A</h2>
        <p>Una historia de aventuras.</p>
      </article>

      <article class="libro">
        <h2>Libro B</h2>
        <p>Una introducción a la ciencia.</p>
      </article>

      <article class="libro">
        <h2>Libro C</h2>
        <p>Un viaje por la naturaleza.</p>
      </article>
    </div>
  </main>
</body>
</html>

Paso 2. Observa el resultado

  1. Abre el archivo en el navegador.
  2. Maximiza la ventana.
  3. Observa cuántas tarjetas aparecen en cada fila.
  4. Reduce poco a poco la anchura de la ventana.
  5. Comprueba cómo cambia la distribución.

Paso 3. Experimenta con CSS

Busca la siguiente parte: 

minmax(min(100%, 16rem), 1fr)

Prueba a cambiar 16rem por 20rem.

Observa si las tarjetas necesitan más espacio y si cambia el número de columnas que caben en la ventana.

Después modifica gap: 1rem por gap: 2rem.

Comprueba cómo aumenta la separación entre las tarjetas.

Paso 4. Comprueba la accesibilidad

  1. Amplía la página al 200 %.
  2. Comprueba que los textos pueden leerse.
  3. Reduce la anchura de la ventana.
  4. Observa si las tarjetas se reorganizan.
  5. Comprueba que no se pierde información.

Resultado esperado

Debes conseguir un catálogo cuyas tarjetas se adapten al espacio disponible sin necesidad de establecer un ancho fijo para cada pantalla.

También debes poder explicar qué hacen las propiedades display: grid, grid-template-columns, minmax() y gap.

Conclusión de la actividad: el diseño responsive no consiste en crear una página diferente para cada dispositivo. Consiste en construir una distribución flexible que responda al espacio disponible.

9. Lista de comprobación antes de desarrollar

Antes de convertir una maqueta en una página web, revisa las siguientes decisiones.

Revisión básica del diseño de una interfaz
Aspecto Pregunta de comprobación
Jerarquía ¿Las personas pueden identificar el título y las acciones principales?
Tipografía ¿El texto tiene un tamaño y espaciado cómodos?
Contraste ¿Los colores cumplen los criterios correspondientes?
Adaptación ¿La distribución funciona en pantallas estrechas y con zoom?
Coherencia ¿Los componentes similares mantienen patrones comunes?
Información ¿Los contenidos mantienen un orden comprensible?
Interacción ¿El diseño contempla foco visible, teclado y mensajes de estado?
Rendimiento ¿Se han evitado recursos innecesarios que dificulten la carga de la página?
Idea final: un diseño web de calidad combina claridad visual, coherencia, adaptación y accesibilidad. La mejor decisión de diseño es la que facilita el uso y puede comprobarse mediante pruebas.
